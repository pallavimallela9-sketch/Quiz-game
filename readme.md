# QuickMind Quiz App

A simple and interactive quiz application built using HTML, CSS, and JavaScript.

## About the Project

QuickMind Quiz is a browser-based quiz application where users can answer multiple-choice questions within a limited time.

The main purpose of this project is to practice JavaScript concepts by creating an interactive web application instead of a static webpage.

## Features

- 10 multiple-choice questions
- 15-second timer for each question
- Automatic answer validation
- Correct and wrong answer highlighting
- Real-time score tracking
- Question progress indicator
- Final score display
- Restart quiz option
- Responsive design for mobile and desktop

## Technologies Used

## How It Works

1. The quiz starts with the first question.
2. The user selects one answer.
3. The selected answer is checked automatically.
4. The correct answer is highlighted.
5. Each question has a 15-second timer.
6. After answering, the user can move to the next question.
7. After all questions are completed, the final score is displayed.
8. The user can restart the quiz and try again.
